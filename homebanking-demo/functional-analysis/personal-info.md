# Análisis Funcional — Mis Datos

**Módulo:** Mis Datos  
**Prioridad:** Media / Alta (Módulo crítico de visualización PII)

## Objetivo
Visualizar de forma centralizada la información personal del usuario, sus cuentas asociadas (con CBU y saldos) y tarjetas vinculadas, garantizando seguridad mediante reglas estrictas de solo lectura.

## Reglas de Negocio Clave
* **Solo Lectura:** Ningún campo de información personal, cuentas o tarjetas puede ser editado o eliminado desde este módulo.
* **Trazabilidad:** Los datos financieros deben mantener estricta consistencia con el Dashboard principal.
